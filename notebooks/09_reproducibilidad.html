9.2 Semillas y determinismo#

  • Semilla global 42 (estrato3/configuracion.py): partición, submuestra, pliegues kNNDM de la repetición 0, modelos, optimizadores (Optuna y DEAP), ajuste cruzado y K-medias del modelo original. Las repeticiones 1–4 de la validación usan las semillas 43–46.

  • Un hilo en BLAS/OpenMP en todos los lanzadores, en las pruebas (tests/conftest.py) y en el dashboard (app.py). Con varios hilos, el orden de las sumas en coma flotante cambia: aparecen diferencias de hasta 0.02 en algunas probabilidades del KNN (empates de distancia) y de 0.003 en el modelo original. Con un hilo, la prueba de ida y vuelta es exacta.

9.4 Orden de ejecución#

Todo se corre desde la raíz del repositorio con python -m experimentos.<script> (ver README.md): 01_particiones → 02_benchmarks_5x5 → 02b_recientes_5x5 → 03_epl_5x5 → 03b_epl_v2_5x5 → 04_estadistica v1 y v2 → 05_descargar_externos → 06_externos (rivales) → 06b_externos_v2 → 07_artefactos → 08_datos_dashboard → 09_test_confirmatorio → 10_datos_modelos_dashboard → 11_robustez → 12_complejidad → 13_tabla_maestra. Cada tarea guarda su resultado y se salta si ya existe, así que las cadenas (experimentos/correr_*.sh) se pueden interrumpir y relanzar. El libro se construye con python book/construir_libro.py a partir de esos resultados.
